# Changelog

All notable changes to VYRONIX are documented here. This project follows a
pre-release development flow; a version is only "released" after every gate in
`docs/RELEASE_READINESS.md` passes.

## [0.1.0] — Unreleased (in development)

### Added
- **Core crate** (`vyronix-core`): honesty-first data model (`Measurement<T>`,
  9-value status), battery health/wear math, ATA/NVMe SMART interpretation,
  weighted scoring with unsupported-exclusion, rule-based diagnostics, use-case
  recommendations, and branded report model with JSON/HTML/CSV serialization.
  **72 unit tests passing; clippy clean.**
- **Frontend** (React 18 + TS + Vite + Tailwind): 21 pages, 12 shared components,
  zustand store, global search palette, dark/light themes, settings, offline PDF
  (jsPDF + autotable). **24 unit tests passing; typecheck + production build clean.**
- **Tauri 2 Windows backend**: WMI/CIM + sysinfo collectors (system/CPU/GPU/memory/
  battery/storage/network), real CPU/memory/storage benchmarks, userspace memory
  test, bounded stress test, ICMP ping + DNS, read-only Windows diagnostics,
  SQLite persistence, local logging, report bundle assembly.
- **Original VYRONIX icon set** (incl. multi-resolution `.ico`) generated by script.
- **CI/CD**: core tests/clippy/fmt + frontend typecheck/test/build (ubuntu); Windows backend
  compile gate; Windows packaging (NSIS + portable) with launch smoke test + SHA-256; tag-driven
  draft-release workflow. Temporary diagnostic helpers removed before release.
- **Documentation**: architecture, 22-phase plan, status, decisions, validation,
  release readiness, security/privacy, limitations, requirements traceability.
- **Manual hardware testing kit**: `docs/MANUAL_HARDWARE_TESTING.md` (step-by-step procedures,
  expected behaviour, pass/fail criteria, evidence, troubleshooting for every module, plus a full
  hardware compatibility matrix), a fill-in test report template, and GitHub issue forms for
  hardware test reports and hardware-specific bugs.

### Fixed
- Windows compile errors: `log` `alloc` feature for `set_boxed_logger`,
  `memory_info` module path, `IcmpCreateFile`/`IcmpSendEcho` API signatures.

### Notes
- A **draft pre-release `v0.1.0`** exists with the portable exe + NSIS installer + SHA-256
  checksums. **Publication is withheld pending explicit owner authorization.** No release assets
  are deleted and no release history is rewritten.
- **Physical-device validation is performed manually by the owner** on real Windows 10/11
  computers and recorded only from submitted, observed results. Automated + Windows CI validation
  (compile, packaging, launch smoke test) are complete.
- Builds are unsigned by design.
